# R9.1 result artifacts (aggregates only)

Produced by `make backtest` on a scratch copy of the development database (see `../candidate-experiment-results.md`). **No
per-player rows** are committed: predictions per player-season (derived from licensed statistics) stay in the git-ignored
`models/experiments/` directory and are regenerated by the same commands.

| Folder / file | What |
| --- | --- |
| `development-<target>/` | the five development folds: `metrics.json` (overall, per fold, per subgroup, paired comparisons, team check), `decisions.json` (the pre-registered rule applied), `attrition.json`, `leakage_audit.json`, `data_snapshot.json` (the fingerprint of the data used) |
| `holdout-<target>/` | the two locked folds, baselines and incumbent only (no candidate advanced) |
| `holdout_ledger.json` | the record that each target's holdout was read once |
| `sensitivity-*/` | evaluation-only cuts at 250 and 1,000 target-season minutes (non-gating) |
| `model_assessment.json` | facts for `../current-model-assessment.md` |
| `goat_readiness.json`, `goat_sample_sizes.json` | aggregates for `../goat-feature-readiness.md` |

# R9.2 result artifacts (aggregates only)

Produced by `python -m app.cli backtest ... --protocol r9.2` and the `backend/scripts/r9_2_*.py` scripts on a scratch copy of the development database
(see `../shooting-validation-results.md`). **No per-player rows** are committed: predictions per player-season (derived from licensed statistics) stay in the
git-ignored `models/experiments/` directory and are regenerated by the same commands.

| Folder / file | What |
| --- | --- |
| `development-<target>/` | the five development folds of `fg3_pct`, `ft_pct`, `ts_pct`: `metrics.json` (overall, per fold, per subgroup, paired comparisons), `decisions.json` (the pre-registered rule applied), `fitted_parameters.json` (every fold's hyperparameters; `at_bound` lists parameters on a search bound), `attrition.json`, `leakage_audit.json`, `data_snapshot.json` (the fingerprint of the data used), `config.json` (the pre-registration as it stood), `run.json` (when it ran), `run_id.txt` (the experiment id) |
| `holdout-<target>/` | the two locked folds: baselines and the candidates that advanced. `fg3_pct`, `ft_pct`: first reads. `ts_pct`: a **re-read** (R9.1 had read it) |
| `holdout_ledger.json` | the record of each holdout read (`reread: true` for `ts_pct`) |
| `sensitivity-development-*` | evaluation-only cuts: 25 and 100 attempts (three-point, free-throw); 250 and 1,000 minutes (true shooting). Non-gating |
| `preregistration.json` | `PREREGISTRATION_R92` including all five dated amendments |
| `shooting_analysis.json` | posterior-predictive check, reliability by attempts, stability of every measured dimension, participation (development folds only) |
| `history_ablation.json` | `ols_history_long` and `state_space_h3`: is the gain "attempts-aware weighting" or "more seasons"? (development only) |
| `baseline_challenge.json` | attempts-aware simple baselines and a fixed-variance state-space variant vs the served models, with the pre-registered checks (development only; added after the independent review) |
| `selection_check.json` | the selection effect behind inferred ability: refit sensitivity and bias by reliability bin; sets the serving floor (development only) |
| `reconstruction_validation.json` | the integer shot-count reconstruction against exact 2025-26 totals and the published rates |
| `availability_study.json` | the scoped availability study (development folds; not a served model) |
| `goat_assessment.json` | what one BALLDONTLIE season can and cannot say (cross-sectional) and the medium-link corroboration check |

The registry the service reads, `backend/app/player_intelligence/validation_registry.json`, is built from these artifacts by `backend/scripts/r9_2_build_registry.py`.
